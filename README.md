S&P 500 Winner Bot

En Python-basert momentumstrategi som hvert år:

1. Henter hvilke selskaper som inngikk i S&P 500.
2. Beregner totalavkastningen til hver aksje for året.
3. Identifiserer aksjen med høyest avkastning.
4. Selger eksisterende posisjon ved årsskiftet.
5. Beregner realisert gevinst/tap.
6. Estimerer norsk skatt etter gjeldende skatteregler
   og skjermingsfradrag.
7. Setter av estimert skatt.
8. Investerer gjenværende kapital i forrige års
   S&P 500-vinner.
9. Logger kjøp, salg, skatt, avkastning og porteføljeverdi.

Strategien sammenlignes kontinuerlig mot S&P 500.
